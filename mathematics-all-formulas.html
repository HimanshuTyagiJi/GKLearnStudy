    Class 9 Math Formulas (कक्षा 9 गणित सूत्र)

    Number Systems (संख्या पद्धति)

    Laws of Exponents for Real Numbers (घातांक के नियम)

    For a > 0, and m, n are rational numbers:

    • aᵐ ⋅ aⁿ = aᵐ⁺ⁿ
    • (aᵐ)ⁿ = aᵐⁿ
    • aᵐ / aⁿ = aᵐ⁻ⁿ
    • aᵐ ⋅ bᵐ = (ab)ᵐ
    • a⁰ = 1
    • a⁻ⁿ = 1/aⁿ
    • (a/b)ⁿ = aⁿ/bⁿ
    Polynomials & Algebraic Identities ( बहुपद और बीजगणितीय सर्वसमिकाएं)

    Key Identities (मुख्य सर्वसमिकाएं)

    • (a + b)² = a² + 2ab + b²
    • (a - b)² = a² - 2ab + b²
    • a² - b² = (a - b)(a + b)
    • (x + a)(x + b) = x² + (a + b)x + ab
    • (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca
    • (a + b)³ = a³ + b³ + 3ab(a + b)
    • (a - b)³ = a³ - b³ - 3ab(a - b)
    • a³ + b³ = (a + b)(a² - ab + b²)
    • a³ - b³ = (a - b)(a² + ab + b²)
    • a³ + b³ + c³ - 3abc = (a + b + c)(a² + b² + c² - ab - bc - ca)

    Example: Factorize 8x³ + 27y³

    1. Identify the form: The expression 8x³ + 27y³ matches the identity a³ + b³.
    2. Determine 'a' and 'b': Here, a = 2x and b = 3y.
    3. Apply the identity a³ + b³ = (a + b)(a² - ab + b²).
    4. Substitute the values:
      = (2x + 3y)((2x)² - (2x)(3y) + (3y)²)

    Final Answer: (2x + 3y)(4x² - 6xy + 9y²)

    Geometry: Lines, Angles & Triangles (ज्यामिति)

    Area of a Triangle (त्रिभुज का क्षेत्रफल)

    Standard Formula: Area = 1/2 × base × height

    Heron's Formula (हीरोन का सूत्र)

    For a triangle with side lengths a, b, and c:

    First, calculate the semi-perimeter (s):

    s = (a + b + c) / 2

    Then, the area is:

    Area = √[s(s - a)(s - b)(s - c)]
    Surface Area and Volume (पृष्ठीय क्षेत्रफल और आयतन)
    • Cube (घन): Surface Area = 6a², Volume = a³ (where a = side)
    • Cuboid (घनाभ): Surface Area = 2(lb + bh + hl), Volume = l × b × h
    • Cylinder (बेलन): Curved Surface Area = 2πrh, Total Surface Area = 2πr(r + h), Volume = πr²h
    • Cone (शंकु): Curved Surface Area = πrl, Total Surface Area = πr(r + l), Volume = (1/3)πr²h (where l = slant height = √(r² + h²))
    • Sphere (गोला): Surface Area = 4πr², Volume = (4/3)πr³
    • Hemisphere (अर्धगोला): Curved Surface Area = 2πr², Total Surface Area = 3πr², Volume = (2/3)πr³

    Class 10 Math Formulas (कक्षा 10 गणित सूत्र)

    Algebra: AP & Quadratic Equations (बीजगणित)

    Arithmetic Progressions (A.P.) (समान्तर श्रेढ़ी)

    An A.P. is a sequence where the difference between consecutive terms is constant (d).

    n-th term (nवाँ पद):

    aₙ = a + (n - 1)d

    Sum of first n terms (n पदों का योग):

    Sₙ = n/2 [2a + (n - 1)d]

    OR

    Sₙ = n/2 [a + l] (where l is the last term aₙ)

    Quadratic Equations (द्विघात समीकरण)

    Standard Form: ax² + bx + c = 0 (where a ≠ 0)

    Quadratic Formula (द्विघाती सूत्र):

    x = [-b ± √(b² - 4ac)] / 2a

    Nature of Roots (मूलों की प्रकृति)

    Based on the Discriminant (विविक्तकर), D = b² - 4ac:

    • If D > 0: Two distinct real roots.
    • If D = 0: Two equal real roots.
    • If D < 0: No real roots.
    Trigonometry (त्रिकोणमिति)

    Basic Ratios and Identities (मूल अनुपात और सर्वसमिकाएं)

    • sin²θ + cos²θ = 1
    • 1 + tan²θ = sec²θ
    • 1 + cot²θ = cosec²θ
    • tan θ = sin θ / cos θ

    Complementary Angles (पूरक कोण)

    • sin(90° - θ) = cos θ
    • cos(90° - θ) = sin θ
    • tan(90° - θ) = cot θ
    Coordinate Geometry & Statistics (निर्देशांक ज्यामिति और सांख्यिकी)

    Distance Formula (दूरी सूत्र)

    Distance between P(x₁, y₁) and Q(x₂, y₂):

    PQ = √[(x₂ - x₁)² + (y₂ - y₁)²]

    Section Formula (विभाजन सूत्र)

    Coordinates of a point P(x, y) dividing the line segment joining A(x₁, y₁) and B(x₂, y₂) internally in the ratio m:n is:

    P(x, y) = [ (mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n) ]

    Mid-Point Formula (मध्य-बिंदु सूत्र)

    P(x, y) = [ (x₁ + x₂)/2, (y₁ + y₂)/2 ]

    Statistics (सांख्यिकी)

    For grouped data:

    • Mean (माध्य): x̄ = Σfᵢxᵢ / Σfᵢ
    • Median (माध्यक): l + [((n/2) - cf) / f] × h
    • Mode (बहुलक): l + [(f₁ - f₀) / (2f₁ - f₀ - f₂)] × h

    Class 11 Math Formulas (कक्षा 11 गणित सूत्र)

    Advanced Trigonometry (उन्नत त्रिकोणमिति)

    Sum and Difference Formulas

    • sin(A ± B) = sinA cosB ± cosA sinB
    • cos(A ± B) = cosA cosB ∓ sinA sinB
    • tan(A ± B) = (tanA ± tanB) / (1 ∓ tanA tanB)

    Multiple Angle Formulas

    • sin(2A) = 2sinAcosA = 2tanA / (1 + tan²A)
    • cos(2A) = cos²A - sin²A = 2cos²A - 1 = 1 - 2sin²A = (1 - tan²A) / (1 + tan²A)
    • tan(2A) = (2tanA) / (1 - tan²A)
    • sin(3A) = 3sinA - 4sin³A
    • cos(3A) = 4cos³A - 3cosA
    Calculus: Limits & Derivatives (कलन: सीमा और अवकलज)

    Standard Derivatives (मानक अवकलज)

    • d/dx (xⁿ) = nxⁿ⁻¹
    • d/dx (sin x) = cos x
    • d/dx (cos x) = -sin x
    • d/dx (tan x) = sec²x
    • d/dx (cot x) = -cosec²x
    • d/dx (sec x) = sec x tan x
    • d/dx (cosec x) = -cosec x cot x
    Conic Sections & 3D Geometry (शंकु परिच्छेद और 3D ज्यामिति)

    Conic Sections (शंकु परिच्छेद)

    • Parabola (परवलय): y² = 4ax
    • Ellipse (दीर्घवृत्त): x²/a² + y²/b² = 1
    • Hyperbola (अतिपरवलय): x²/a² - y²/b² = 1

    3D Geometry (3D ज्यामिति)

    Distance between P(x₁, y₁, z₁) and Q(x₂, y₂, z₂):

    PQ = √[(x₂ - x₁)² + (y₂ - y₁)² + (z₂ - z₁)²]

    Class 12 Math Formulas (कक्षा 12 गणित सूत्र)

    Calculus: Integration (कलन - समाकलन)

    Standard Integrals (मानक समाकलन)

    • ∫ xⁿ dx = (xⁿ⁺¹ / (n+1)) + C
    • ∫ (1/x) dx = log|x| + C
    • ∫ eˣ dx = eˣ + C
    • ∫ sin x dx = -cos x + C
    • ∫ cos x dx = sin x + C
    • ∫ sec²x dx = tan x + C
    • ∫ dx / √(a² - x²) = sin⁻¹(x/a) + C
    • ∫ dx / (a² + x²) = (1/a)tan⁻¹(x/a) + C

    Integration by Parts (खंडशः समाकलन)

    Formula: ∫ u v dx = u ∫v dx - ∫( (du/dx) ∫v dx ) dx

    Often remembered using the ILATE rule for choosing the first function (u).

    Vectors and 3D Geometry (सदिश तथा त्रि-विमीय ज्यामिति)

    Vector Products (सदिश गुणन)

    Dot Product (अदिश गुणन): a · b = |a| |b| cos θ

    Cross Product (सदिश गुणन): a × b = |a| |b| sin θ n̂

    3D Geometry: Lines & Planes (रेखाएं और समतल)

    Shortest Distance between two skew lines r = a₁ + λb₁ and r = a₂ + μb₂:

    d = | (b₁ × b₂) · (a₂ - a₁) | / |b₁ × b₂|

    Equation of a plane in normal form: r · n̂ = d

    Probability (प्रायिकता)

    Conditional Probability (सप्रतिबन्ध प्रायिकता)

    P(A|B) = P(A ∩ B) / P(B)

    Bayes' Theorem (बेज़ प्रमेय)

    P(Aᵢ|B) = [ P(Aᵢ) P(B|Aᵢ) ] / [ Σ P(Aⱼ) P(B|Aⱼ) ]

    Binomial Distribution (द्विपद बंटन)

    P(X=r) = ⁿCᵣ pʳ qⁿ⁻ʳ

    Where n = number of trials, r = number of successes, p = probability of success, q = probability of failure (1-p).
