    How to Use This Periodic Table

    This interactive periodic table is designed for students, teachers, and exam aspirants. Use the search box to quickly find an element by its name or symbol (for example: Na, O, Fe). You can filter by block, metal/nonmetal type, or state to focus only on the elements you need.
